Boostore.pro — Management Scripts
==================================

These PHP scripts allow you to **import** (download) and **export** (upload) data
from your Boostore.pro site via the Commerce API.

Available scripts in `/ai_boostore/`:

  products.php              — Shop products (prices, stock, images, categories, etc.)
  blog.php                  — Blog articles (multilingual, categories, tags)
  shop_categories.php       — Shop categories (hierarchy, images, SEO)
  shop_producers_categories.php — Shop producers (brands, hierarchy, images, SEO)
  shop_collections_categories.php — Shop collections (groups, hierarchy, images, SEO)
  pages.php                 — Site pages
  blocks.php                — Site blocks/menus

What they do:

  • Import — fetch data from API, save as local HTML files
  • Export — read local HTML files, send back to API (create or update)
  • Batch operations, dry-run mode, auto-fix by reference language
  • Debug mode with `&debug=1` for troubleshooting

File naming:

  Each record is saved as a single HTML file:
    {id}[-{name}]-{lang}.html
  Example: 123-my-product-ru.html, 456-ua.html

  The HTML file contains:
    • <meta name="..." content="..."> tags for all fields
    • Content separators for multi-section text (products: tabs, articles: body)

Data fields:

  Products — title, slug, description, price, stock, SKU, images, variations,
              categories, producer, attributes, SEO meta, etc.

  Articles — title, slug, body, categories, tags, SEO meta, etc.

  Categories — name, title, parent, image, text, SEO meta, etc.

  Producers — name, title, parent, image, text, SEO meta, etc.

  Collections — name, title, parent, image, text, SEO meta, etc.

API documentation:
  https://boostore.pro/en/docs/api-integration/#hotengine-CommerceAPI
